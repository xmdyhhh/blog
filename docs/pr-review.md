**意见1**: 导航栏中文化是否会影响其他语言用户？

**意见2**: oss-custom.css 中是否有重复样式与原主题冲突？

**意见3**: 搜索 JS 中的 API Key 是否安全？
- **回复**: 使用的是 Content API Key（只读权限），不是 Admin API Key。Content API Key 设计上就是可以在前端使用的，仅能读取公开内容，无法修改数据。

### Review 意见与修改

**意见1**: 相关文章推荐仅使用 primary_tag，是否可以考虑多标签匹配？
- **回复**: Ghost 的 {{#get}} 助手 filter 参数支持复杂查询，但多标签匹配的语法较复杂且性能可能受影响。当前使用 primary_tag 已能满足实验需求，且实现简单可靠。未来可优化为多标签加权匹配。

**意见2**: 搜索功能是否考虑了中文分词？
- **回复**: Ghost Content API 的搜索使用 SQLite 的 LIKE 查询，对中文支持有限（只能精确匹配连续字符）。当前实现已能满足基本搜索需求，更复杂的中文分词需要引入 Elasticsearch 等外部服务，超出本实验范围。

**意见3**: 测试用例是否有自动化执行？
- **回复**: 本实验的测试为人工验收测试，记录在 tests/acceptance.md 中。自动化测试（如 Playwright E2E 测试）作为未来改进方向，已在 README 的"改进方向"中列出。
