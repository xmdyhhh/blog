## 请求流程

1. **前台文章浏览**: 浏览器 → Ghost 主题引擎 → 内容服务 → SQLite → Handlebars 模板渲染 → HTML
2. **管理后台操作**: 浏览器 → /ghost → Ember Admin → Admin API → Ghost 核心 → SQLite
3. **会员评论**: 会员登录 → 评论提交 → 评论服务 → SQLite → 前台刷新显示
4. **搜索**: 搜索关键词 → 搜索 API → 内容索引 → 返回结果 → 主题渲染（含高亮）

## 修改边界

### 允许修改的目录
- `theme/oss-blog-theme/` - 自定义主题源码
- `docs/` - 项目文档
- `tests/` - 测试用例
- `scripts/` - 辅助脚本

### 禁止修改的目录
- `runtime/current/` - Ghost 核心代码（上游项目）
- `runtime/versions/` - Ghost 版本文件
- `runtime/content/data/` - 数据库文件（通过管理界面操作）

## 数据流向

- **内容数据**: 管理员通过 /ghost 后台创建 → Ghost 核心 → SQLite → 前台主题渲染
- **会员数据**: 会员注册/登录 → Ghost 会员系统 → SQLite → 评论权限验证
- **评论数据**: 会员提交评论 → Ghost 评论系统 → SQLite → 文章详情页显示
- **搜索数据**: 搜索关键词 → Ghost 搜索 API → 内容索引 → JSON 结果 → 主题前端渲染
